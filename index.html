Overview

Abstract

Zero-shot object navigation (ZSON) enables agents to search for target objects without additional policy training, offering strong generalization across diverse object categories. Nevertheless, most agents struggle to leverage experience and commonsense reasoning as humans do, while egocentric observations provide limited spatial layout information, resulting in inefficient exploration across multiple rooms. To overcome these limitations, we propose RSM-Nav, a hierarchical ZSON framework that combines the room-level semantic map with egocentric observations to guide online exploration. Specifically, the proposed method employs a large language model (LLM) to perform semantic reasoning over the room-level semantic map, generating the object spatial probability distribution and room-level candidate exploration nodes (RCENs). Furthermore, real-time observations are fed into a visual language model (VLM) to extract visual-language cues, which are further integrated with the inferred room-level spatial representations to determine promising navigation points. Building on this, we adopt a coarse-to-fine hierarchical search mechanism, which decomposes the ZSON task into coarse-grained cross-room guidance and fine-grained intra-room exploration, avoiding excessive local search while prioritizing the exploration of high potential regions. Experiments on Habitat-Matterport 3D (HM3D) and Matterport 3D (MP3D) show that RSM-Nav achieves state-of-the-art ZSON performance, surpassing the leading ZSON baseline by 4.6% and 23.8% in Success Rate (SR) and Success weighted by Path Length (SPL). In real-world deployment, RSM-Nav achieves a 133.3% relative gain in SR over the baseline. Videos of real-world deployment are available on our website.

The approach

Room-level semantics.
Hierarchical search.

RSM-Nav employs a coarse-to-fine hierarchical search mechanism comprising coarse-grained cross-room guidance and fine-grained intra-room exploration.

01 / SEMANTIC REASONING

Room-level semantic map processing

The LLM estimates the probability of finding the target object in each room. The object spatial probability distribution is fused with the value map for navigation decision-making, while room-level candidate exploration nodes (RCENs) serve as candidate navigation points for cross-room guidance.

02 / VISUAL OBSERVATIONS

Real-time observation processing

A VLM extracts target-related visual-language cues from real-time observations. Dynamic weighted fusion enables the agent to prioritize egocentric observational results over initial room-level semantic predictions when real-time observation data is reliable.

03 / HIERARCHICAL SEARCH

Coarse-to-fine navigation

The agent switches cyclically between the coarse-grained guidance mode and fine-grained initialization and exploration modes. Once the target object is detected, the system transitions to navigation mode and the agent proceeds to the target object's location.

↔

Remote computation, physical execution. The navigation system can run on a server that receives observations from the robot and returns motion commands, without running the full system onboard.

Simulation benchmarks

Simulation experiments.

We compare the object navigation performance of RSM-Nav against baselines on HM3D and MP3D, with 2,000 and 2,195 episodes, respectively.

As shown in TABLE I, we compare RSM-Nav with baselines on HM3D and MP3D. The results show that RSM-Nav achieves state-of-the-art ZSON performance on all benchmarks, surpassing the leading ZSON baseline by 4.6% (SR) and 23.8% (SPL) on HM3D, and by 2.4% (SR) and 1.7% (SPL) on MP3D. Furthermore, RSM-Nav even surpasses some supervised methods, further demonstrating its superiority.

From simulation to the physical world

Real-world deployment.

We deploy RSM-Nav on a wheeled mobile robot and evaluate its object navigation performance in a multi-room indoor environment. The distribution of navigation trajectories is visualized as a density heatmap.

Real-world results

We evaluate RSM-Nav and VLFM on 20 episodes each.

As reported in TABLE VI, RSM-Nav outperforms VLFM across all evaluated metrics. The 75.0% reduction in NFR suggests that coarse-grained semantic guidance alleviates blind exploration and helps the robot reach promising regions, contributing to a 133.3% improvement in SR over VLFM. Meanwhile, reductions of 33.0% in AS and 27.3% in ART indicate that successful searches require fewer navigation steps and room transitions, reflecting improved cross-room search efficiency.
